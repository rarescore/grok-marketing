# React/Vite creative source

This folder mirrors the standalone build using the requested stack:

- React + Vite
- React Three Fiber + drei
- Three.js
- GSAP + ScrollTrigger
- Lenis
- Tailwind CSS

Run with a public npm registry:

```bash
npm install
npm run dev
```

The root folder contains the immediate no-build version for direct preview. The main asset to replace later is `public/assets/rs-formula-car.png`; a compressed GLB can be substituted inside `src/experience/Experience.jsx` when the final custom car model is ready.
