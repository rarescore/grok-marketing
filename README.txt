RS MEDIA REAL-TIME 3D BUILD

This version uses:
- One local GLB car model
- Three.js real-time rendering
- Scroll-controlled car and camera motion
- No WebP frame sequence
- No 130-frame loading screen

Deploy:
1. Upload every file and folder to your repository root.
2. Vercel Framework Preset: Other
3. Build command: leave blank
4. Output directory: leave blank
5. Deploy

Required root structure:
index.html
style.css
main.js
models/rs-formula.glb
